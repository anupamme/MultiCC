添加一台电脑

那台电脑需要先装好 MultiCC。两种方式二选一：

在那台电脑上输入配对码

打开那台电脑的 MultiCC → 更多与系统 → 电脑管理 → 「加入另一台电脑」，或在终端执行：

K7Q-4M2
multicc pair K7Q-4M2
手机 App 扫码也能把这台电脑加进来。配对码 5 分钟内有效、只能用一次；配对成功后双方交换一枚只属于这对电脑的令牌，存进各自的敏感信息保险箱，不会出现在聊天或日志里。
